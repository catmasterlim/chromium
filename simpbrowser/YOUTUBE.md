# SimpBrowser 유튜브 기능

## 사용 방법

`SimpBrowser.cmd`를 실행하면 전용 프로필로 유튜브를 엽니다.
화면 위에 뜨는 **SimpBrowser · 1080p** 버튼과 설정 패널은 기본적으로 숨깁니다.
설정을 바꾸려면 유튜브에서 **Alt+Shift+Y**로 표시하고, 같은 단축키로 다시 숨깁니다.
표시 여부도 해당 사이트에 저장합니다. 숨겨도 화질 고정과 광고 제거는 계속 작동합니다.

- 기본 화질: **1080p**. 영상이 지원하는 화질 중 선택한 해상도 이하의
  가장 높은 화질을 적용합니다. 144p부터 최고 화질 및 자동 모드를 선택할 수 있습니다.
- 화질은 유튜브 내부 페이지 전환 후에도 다시 적용합니다.
- 광고 제거는 기본으로 켜져 있습니다. 끄거나 켜면 페이지를 새로고침합니다.
- 설정은 현재 프로필의 해당 유튜브 사이트 저장소에 보관합니다.
  `www.youtube.com`, 모바일 사이트, 임베드 사이트의 설정은 서로 독립적입니다.
- 시크릿 모드 및 저장소가 제한된 임베드에서는 영구 저장이 제한될 수 있습니다.

## 적용 범위

Chromium 렌더러가 HTTPS `youtube.com`, `youtube-nocookie.com`과 그 하위 도메인에만
번들 스크립트를 주입합니다. 확장 프로그램 설치나 외부 스크립트 다운로드는 없습니다.
일반 웹사이트에는 이 기능을 적용하지 않습니다.

광고 처리는 다음을 조합합니다.

1. 초기 플레이어 데이터와 player API 응답의 광고 필드 제거.
2. 알려진 광고 서버/경로에 대한 페이지의 fetch·XHR·sendBeacon 요청 차단.
3. 렌더러 요청 단계에서 이미지·스크립트 등의 알려진 광고 목적지를 빈 로컬 리소스로 대체.
   유튜브 문서가 광고 제거를 켠 경우에만 적용하며, 끄면 이 필터도 해제합니다.
4. 광고 전용 화면 요소 숨김.
5. 광고 재생 상태에서 건너뛰기 버튼을 누르거나, 길이가 유한한 광고를 끝으로 이동.

일반 영상의 재생 속도와 재생 위치는 변경하지 않습니다.
영상 스트림과 광고가 아닌 요청은 그대로 보냅니다.
이 모듈은 브라우저 전체의 네트워크 필터가 아니며, 모든 리소스 종류를 차단하지 않습니다.
유튜브의 내부 API·광고 방식 변경, 서버 측 삽입 광고, 계정별 실험에 따라 대응이 필요합니다.
모든 영상의 광고 제거와 항상 1080p 재생을 보장하지 않습니다.

## 로컬 광고 진단

유튜브에서 **Alt+Shift+Y** → **SimpBrowser** 버튼 → **광고 차단 · 진단 통계**를
열면 요청 차단 합계·페이지/렌더러별 차단·광고 데이터 처리·건너뛰기 시도·리소스 관찰·
재생 오류·응답 해석 오류·진단 기록 수를 확인할 수 있습니다. 메뉴가 열려 있는 동안
실시간으로 갱신합니다. **최근 진단 이벤트**를 펼치면 최근 6건을 시간과 유형으로 보여줍니다.

페이지 수치는 새로고침/새 문서에서 초기화됩니다. **페이지 수치 초기화**는 수치만 지우고
기록은 유지합니다. **진단 기록 삭제**는 이벤트만 지우며 진단 기능은 계속 켜 둡니다.
통계 표시와 실제 카운터 일치, 수치 초기화 시 기록 유지, 기록 삭제 시 수치 유지까지
포함한 최신 브라우저 기능 테스트 **29개**가 통과했습니다.

유튜브 문서의 차단 건수, 광고 상태 전환, 광고 처리 시도, 미디어 오류 코드,
재생 지연, 광고 리소스 관찰 이벤트를 기록합니다. 관찰된 광고 리소스가 곧
실제 광고 노출이나 차단 실패라는 뜻은 아닙니다. 오류도 광고와 무관한 네트워크
문제로 발생할 수 있습니다. 관찰 결과만으로 새 차단 규칙을 자동 적용하지 않습니다.

- 기록은 현재 탭의 `sessionStorage`에 최대 **128건**, 고정 이벤트명·숫자·유형만 저장합니다.
- 방문 주소, 검색어, 영상 ID·제목, 쿠키, 요청 본문·응답 내용은 저장하지 않습니다.
- 기록은 외부 서버로 전송하지 않습니다.
- **Alt+Shift+Y**로 버튼 표시 → **SimpBrowser** 버튼 → **진단 JSON 저장**으로
  사용자가 직접 파일을 저장할 수 있습니다. 작은 창에서는 설정 안을 스크롤할 수 있습니다.
- **로컬 진단 기록**을 끄면 기록을 삭제하고 추가 저장을 중단합니다.
- 탭을 닫으면 세션 기록이 사라집니다. 저장한 JSON 파일은 별도 보관됩니다.

문서 시작 전 preload나 별도 worker에서 발생한 요청 등에는 추가 대응이 필요할 수
있습니다. 이는 방문 기록 전체를 수집하거나 이미 사용한 브라우저 활동을 소급 분석하는
기능이 아니라, 새 버전 실행 이후의 유튜브 재생 진단입니다.

## 개발 및 검증

개발 브랜치: `simpbrowser`.

```powershell
.\build-youtube.cmd
```

기존 `out/SimpBrowser` 설정으로 증분 빌드한 뒤 기존 기본 테스트와
`node test-youtube.mjs --live`를 실행합니다.
빌드 중에는 같은 출력 폴더의 브라우저를 실행하지 마세요.
Windows가 사용 중인 DLL의 교체를 거부할 수 있습니다.

- `youtube-configure.log`: GN 설정 생성
- `youtube-build.log`, `youtube-build.exitcode`: 컴파일 결과
- `youtube-checks.exitcode`: 기본·기능 테스트 통합 결과
- `test-results/youtube-native/results.json`: 내장 모듈의 브라우저 테스트
- `test-results/youtube-native/settings.png`: 설정 UI 캡처
- `test-results/youtube-native/youtube-live.png`: 실영상 재생 캡처

`node test-youtube.mjs --inject-script`는 이전 실행 파일에서 모듈 스크립트만
검증하는 개발용 모드입니다. 실제 내장 여부는 주입 옵션 없이 별도로 검증합니다.

제품명과 Windows 제품 메타데이터는 SimpBrowser로 변경합니다.
Chromium 빌드 구조와 호환성을 위해 내부 실행 파일명은 `chrome.exe`를 유지합니다.
원본 Chromium 저작권 표시와 웹 호환용 User-Agent는 유지합니다.

## 검증 결과 — 2026-11-13

- 실제 내장 모듈 테스트 **19개 통과** (테스트 스크립트 주입 없이 실행).
- 기존 URL 단위 테스트 **182개 통과**.
- 기본 브라우저 실행·JavaScript·WebM 재생·유튜브 홈페이지 테스트 통과.
- 실제 유튜브 샘플 영상에서 **1920×1080**, 플레이어 화질 **hd1080**,
  재생 시간 **12.70초**, 일시 정지되지 않은 상태를 확인.
- 해당 재생에서 알려진 광고 요청 1건 차단, 측정 시점 광고 재생 상태 없음.
  이 짧은 검사는 모든 영상·계정·광고 형식의 제거를 보장하는 검사가 아닙니다.
- Windows 제품명·파일 설명과 `chrome://version`의 제품명이 **SimpBrowser**임을 확인.

광고 데이터 제거, fetch/XHR 광고 요청 차단, 일반 미디어 요청 보존, 화질 fallback,
페이지 전환, 설정 저장·해제, 광고만 건너뛰기, 유사 도메인 미적용은
브라우저 내 재현 페이지로 별도 검증했습니다.

### 광고 진단·요청 필터 보완 검증

- 내장 모듈 브라우저 테스트 **26개 통과**, 기존 URL 테스트 **182개 통과**.
- 광고 이미지·스크립트와 beacon 차단, 필터 해제 시 요청 허용,
  다른 사이트에 필터 미적용을 검증했습니다.
- 차단된 광고 이미지의 깨진 아이콘 숨김도 확인했습니다.
- 진단 기록 128건 제한, 요청 URL·본문 미포함, 기록 해제·삭제를 검증했습니다.
- 실제 유튜브 영상이 1920×1080으로 17초 이상 재생됐고,
  페이지 요청 1건·렌더러 요청 1건 차단, 광고 데이터 처리 2회,
  재생 오류·응답 파싱 오류 0건을 확인했습니다.
- 단기 재생 샘플이며 모든 광고 유형을 검증했다는 뜻은 아닙니다.

## 릴리스 빌드

```powershell
.\build-release.cmd --configure-only
.\build-release.cmd
.\SimpBrowser-Release.cmd
```

설정 생성은 검증했습니다. 전체 릴리스 컴파일은 별도로 실행해야 합니다.
현재 개발용 실행 파일은 디버그 빌드입니다. 릴리스는 `out/Release`에 생성하며
최적화를 켜고 디버그 검사·심볼을 끕니다. 자세한 옵션과 로그는 `BUILD.md`를 참고하세요.
